Credits & Sources

This site is built on work that other people made and shared. Some of it carries conditions we're obliged to honour; some of it is simply owed thanks. Both are listed here.

Software

The map on this site is drawn in your browser by these open-source libraries, served from this site rather than someone else's server so the pages keep working regardless of what happens elsewhere. The rest of this list is the tools used to build the site and do the actual research — transcription, translation, and the pipeline itself (see How This Was Made for the full account).

MapLibre GL JS (v4.7.1)BSD 3-Clause
Draws the interactive maps.
© MapLibre contributors
PMTilesBSD 3-Clause
Lets a single map-tile file be read straight from this site, so the historical maps need no outside server.
© Protomaps
maplibre-gl-datesCC0-1.0
Filters the map to a chosen year, so a 1912 map shows 1912.
OpenHistoricalMap — released into the public domain (CC0-1.0); credited here by choice.
GoatCounterISC
Counts visits to the site — how many people come and which pages they read. No cookies, no personal data, and nothing that identifies an individual reader.
GoatCounter — count.js by Martin Tournoij, ISC-licensed
TranskribusProprietary — commercial service
Handwriting-recognition model trained on real early-20th-century Yiddish script. It did the first pass at turning the letters' handwriting into text — the only tool trusted to read the Yiddish itself, precisely because it was measured against known pages.
ClaudeProprietary — commercial service
Did double duty: wrote the software (pipeline, honesty checks, the site itself) and did the interpretive work (translation, theme extraction, shaping the narrative). Never given the final word on what's true — a person confirms every reading.
GeminiProprietary — commercial service
A second, independent translator, used as a cross-check against Claude's readings — where the two agreed, that agreement carried more weight; it was never allowed to quietly overrule the primary reading.
ComfyUIlicence not yet verified
The local pipeline behind the site's AI-generated assets — already used for the ambient sound cue (see Sound, below); regenerating the illustrated portraits from recipes is planned next, so even the artwork stays reproducible rather than hand-made once and forgotten.
