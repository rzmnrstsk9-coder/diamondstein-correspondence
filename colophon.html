Typography

Headings and display text are set in Bricolage Grotesque; running text is set in Inter; annotations, dates, and machinery-facing labels use IBM Plex Mono. All three are open-source typefaces, chosen for a clear distinction between voice — a heading announces, body text narrates, mono text records — and reused everywhere on the site rather than styled per page.

How This Page Was Built

This page is not hand-written HTML. It is a small JSON payload — a title and a few named sections — that a generic build step turns into a page: no bespoke template, no per-page registration. The same machinery builds every page like it. Colors, spacing, and heading size are chosen from a fixed set of named tokens shared by the whole site, never a one-off hex value or pixel size, so a new page can never drift from the site's visual language by accident.
